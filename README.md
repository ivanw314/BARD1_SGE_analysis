# BARD1_SGE_analysis

This repository contains all Python notebooks and scripts used to create figures, tables, and numerical figures used in the BARD1 SGE paper. All notebooks/scripts are organized into one of two folders, Notebooks and Scripts. Datasets used to generate figures are located in the Data folder. Unless otherwise stated, all notebooks and scripts used for figures can be made using the supplementary_file_1_BARD1_SGE_final_table.xlsx found in the final_tables sub-folder in the Data folder.

Required supplementary data tables and paths are already set for all notebooks. To regenerate figures, simply clone this repository. For figures generated through Python scripts, paths will need to be updated based on your local machine.

## Data
The data folder contains sub-directories containing all supplementary tables, data needed to generate figures, and catalog of reagents/oligonucleotides used. Data used to recompile provided supplementary data tables is also provided.

Each supplementary table/file (`supplementary_file_1`, `supplementary_file_2`, `supplementary_table_1`, `supplementary_table_2`) documents its own tabs and columns in a `README` sheet embedded in the workbook itself -- there is no separate column-keys file anymore.

## extra_data
Contains all external data used for analysis and figure generation, such as: BRIDGES and CARRIERS case-control data, BRCA1 SGE data, ThermoMPNN/SASA structural predictions, and the X4A intrinsically disordered region (IDR) library.
* BRCA1_SGE_data.xlsx - Contains BRCA1 SGE data from Findlay et al. 2018 and Dace et al. 2025 in separate tabs **(BRCA1 SGE File)**
* 20260723_BARD1.allscores_wD17.tsv - Whole-gene SGE scores recomputed with a day 17 timepoint added, used to check score stability at extended culture time (Extended Data Fig. 8)
* 20260830_BARD1LoFVars_wThermoMPNN.xlsx - Missense ddG (ThermoMPNN) and solvent accessibility (SASA) predictions for the RING/ARD/BRCT domains, merged into `supplementary_file_1`'s `scores` tab. Regenerated by `SGE_InSilicoDeltaDeltaGAnalysis.ipynb`
* 20260603_BARD1_X4A_IDR_LibA.csv / 20260603_BARD1_X4A_IDR_LibB.csv - Designed oligo sequences for the X4A IDR library (Lib A: SNVs + Lys->Ala/Lys->Arg/AAE combination mutants + 6bp deletions; Lib B: ClinVar indel recreations + full site-saturation mutagenesis), designed by `SGE_BARD1_X4_IDR_libs.ipynb`
* 20260812_BARD1_X4A_IDR_LibA_LFCs.tsv / 20260812_BARD1_X4A_IDR_LibB_LFCs.tsv - Raw log-fold-change read counts for the X4A IDR libraries
* 20260828_BARD1_X4A_IDR_LibA_aminoacidsat_fitness_scores.tsv - Model-fit fitness scores for the Lib B full-saturation scan
* ThermoMPNN_data - Per-domain (RING/ARD/BRCT) ThermoMPNN ddG predictions for missense variants (`BARD1_{domain}.csv`) and single-residue in-frame deletions (`BARD1_{domain}_dels.csv`, "ThermoMPNN-I")
* SASA_data - Per-domain (RING/ARD/BRCT) solvent accessibility predictions, keyed to their solved structures (1JM7/3C5R/3FA2)

The case_control_data sub-folder contains data accessed from the BRIDGES and CARRIERS breast cancer case-control studies. Data for each study is organized into its respective folder:
* BRIDGES_data - Contains all data files from the BRIDGES study
  * 20250815_BRIDGES_missense_all.xlsx - All missense variants sequenced in the BRIDGES study
  * 20250815_BRIDGES_missense_population.xlsx - Missense variants only from population-based studies that were part of the BRIDGES study
  * 20250815_BRIDGES_PTVs_all.xlsx - All PTVs sequenced in the BRIDGES study
  * 20250815_BRIDGES_PTVs_pop.xlsx - PTVs only from population-based studies that were part of the BRIDGES study

* CARRIERS_data - Contains data file from the CARRIERS study
  * 20250303_CARRIERS_data.xlsx - Contains all variants sequenced in the CARRIERS case-control study.

## final_tables
Contains all final supplementary tables. Includes final table for figure generation, output of case-control analysis, and all oligos used in experiments
* supplementary_file_2_BARD1_all_reagents.xlsx - Multi-tabbed file containing sequences and descriptions of all oligos and reagents used in experiments (Supplementary File 2)
* supplementary_table_1_BARD1_OddsRatios_table.xlsx - Supplementary table containing raw number of variants going into the case-control analysis done utilizing the BRIDGES and CARRIERS cohorts done in this study (Supplementary Table 1)
* supplementary_file_1_BARD1_SGE_final_table.xlsx - Large supplementary table containing all data from this study in multiple tabs. Used as input for all figure generation and analysis (Supplementary File 1)
* supplementary_table_2_BARD1_variant_reclass_table.xlsx - Multi-tabbed file containing controls, OddsPath calculations, and evidence used in reclassification of VUS (Supplementary Table 2)

### supp_table_inputs
Files used to create the BARD1_final_table supplementary table are found in the **supp_table_inputs** sub-directory. Files are dated based on when they were originally created/when data was accessed. These files are:
* 20240802_BARD1_Regeneron_MAF.xlsx - MAF data from Regeneron's Million Exome study
* 20240905_BARD1_gnomADv4.1.0_SNVs.xlsx - MAF data for BARD1 SNVs accessed from gnomAD v4.1.0
* 20241016_Orthogonal_BARD1_FunctionalAssays.xlsx - Curated list of variant previously assayed in orthogonal assays. Variants are listed along with the assay performed and performance of the variant
* 20241217_BARD1_sgRNA_cutsites.xlsx - List of 1-based, hg38 genomic coordinates for Cas9 cut sites based on designed sgRNAs for each SGE target
* 20250415_BARD1_filter_entry.xlsx - Contains sheet of genomic coordinates for all SGE targets
* 20250912_BARD1_ClinVarDels_1StarPlus.txt - Contains in-frame deletion variants accessed from Clinvar with at least 1-star review status
* 20250912_BARD1_ClinVarSNVs_1StarPlus.txt - Contains SNVs accessed from Clinvar with at least 1-star review status
* 20250912_BARD1_SGEoligos.xlsx - All programmed SGE library oligos
* 20250926_BARD1.editrates.sorted.tsv - Editing rates generating useable reads for each SGE target and replicate
* 20251002_BARD1snvs_VEP.xlsx - Ensembl VEP annotated SNVs file
* 20251006_BARD1_MutPred2.xlsx - MutPred2 scores for coding missense SNVs
* 20251008_PhyloP.xlsx - PhyloP scores across BARD1
* 20260218_BARD1_pos_aapos.tsv - Describes genomic position and amino acid of BARD1 at that genomic position
* 20260602_BARD1_Pangolin_D500.vcf / 20260602_BARD1_SpliceAI_D500.vcf - Pangolin and SpliceAI splicing predictions computed with a 500bp window
* 20260807_BARD1.allscores.tsv - Raw SNV and 3bp-deletion SGE scores **(SGE scores file)**
* 20260807_BARD1.delcounts.tsv - Raw 3bp-deletion counts across all SGE targets and replicates (not currently merged into a final table)
* 20260807_BARD1.modelparams.tsv - Output parameters from GMM modeling. Gives best estimated thresholds for functional class classification
* 20260807_BARD1.snvcounts.tsv - Raw SNV counts across all SGE targets and replicates
* 20260901_BARD1delscores.vcf / 20260901_BARD1snvscores.vcf - .VCF file inputs for Ensembl VEP annotation (to variant effect predictor scores)

The supp_table_inputs sub-directory also contains two additional folders
* ATG_lib_data - Contains all data needed to recompute results from the X1A_ATG double mutant experiment
  * X1A_annotations.xlsx - Contains variant annotations for library X1A **(X1A annotations file)**
  * 20260723_BARD1_X1A_ATG_scored_wD17.xlsx - Scores from the X1A_ATG double mutant experiment, including a day 17 timepoint in addition to day 5/13
  * counts - Folder contains .tsv files with raw counts of variants for each replicate **(ATG counts folder)**. `counts/for_rna` contains the DNA/RNA count subset read by `SGE_ATGlib_AnnotateCounts.ipynb`
* depth_data - Contains all data needed to recompute normalized depth values
  * deletion_inputs.xlsx - Contains coordinates for start and stop of each BARD1 coding exon
  * depth_files - Folder contains read depths at each base for each library and replicate

## Notebooks
The Notebooks folder contains Python Notebooks that create individual panels used in the final figures and the supplementary tables. The visualization that will be created by each notebook is noted in the name of the notebook. Code in notebooks have been annotated and each contains a Markdown header describing the figure or table it produces (or, for non-figure notebooks, its role in the pipeline).

These notebooks are:
* SGE_AbnormalVCF - Generates .VCF file used as the input to Ensembl's VEP tool to get variant effect predictor annotations for AlphaMissense, REVEL, CADD, and SpliceAI. **(Needs SGE scores file)**
* SGE_ARD_analylsis - Generates heatmap by type of amino acid introduced at positions of the BARD1 ARD that interact with the histone tail (Fig. 5c).
* SGE_ATGlib_AnnotateCounts - Annotates raw counts files from the X1A ATG double-codon mutant experiment; output is used by SGE_ATGlib_analysis. **(Needs ATG counts folder)**
* SGE_ATGlib_analysis - Generates continuous log-fold change scores for variants in the BARD1_X1A double start codon mutant experiment as well as basic visualizations of the results. **(Needs ATG counts folder and X1A annotations file)**
* SGE_ATGlib_HeatMap - Generates heat map visualizations of BARD1_X1A double start codon mutant experiment faceted by canonical start (Fig. 4b).
* SGE_BARD1_DomainAnalysis - Generates strip plot showing distribution of missense scores across BARD1's domains, including the IDR (Fig. 2e). Also computes % LoF-missense per domain, a cumulative-percentage plot by domain, and a RAD51-binding-region analysis within the IDR (not individually figure-numbered).
* SGE_BARD1_X4_IDR_libs - Designs the oligo sequences for the X4A IDR library (Library A: SNVs, Lys->Ala/Lys->Arg combinatorial mutants, AAE/FXDA combos, 6bp deletions; Library B: ClinVar indel recreations, full site-saturation mutagenesis). No figure is produced here.
* SGE_BARD1vBRCA1 - Comparative analysis of missense sensitivity of BARD1 and BRCA1 domains. Also builds Fig. 5e (phosphopeptide-binding-site heatmaps) and a supplementary bar plot comparing % LoF variants between genes. **(Needs BRCA1 SGE File)**
* SGE_CaseControlAnalysis - Case-control analysis of BARD1 variants using the BRIDGES and CARRIERS breast cancer case-control cohorts. Output used in Fig. 3c and the supplementary_table_1 OddsRatios table. **(Needs BRIDGES and CARRIERS data)**
* SGE_ClinVar_analysis - Generates strip plot (and histogram) of ClinVar variants seen in SGE and does ROC analysis (Figs. 3a-b).
* SGE_Correlation_analysis - Generates Pearson's r boxplots across timepoints and regions and a Pearson r heatmap across all SGE sub-targets (Extended Data Fig. 1b-c).
* SGE_DeletionFigs_Heatmap - Generates Fig. 2a (3bp deletion map), 2b (missense/stop-gained heatmap), 2c (min/mean fitness + predictor score heatmap with a phyloP track), and Extended Data Fig. 5 (median read depth plot).
* SGE_EditRate_BarPlot - Generates SGE target-faceted bar plot showing editing rate generating usable reads across all targets and replicates (Extended Data Fig. 1a).
* SGE_GMMThreshold_Plot - Visualizes the already-fitted Gaussian mixture model components used to classify variants as functionally abnormal/normal (Extended Data Fig. 3). The GMM fitting itself happens elsewhere in the pipeline; reads from a hardcoded cluster path that needs updating before rerunning.
* SGE_Histogram_Stripplot - Creates histogram (top) and strip plot (bottom) of all BARD1 SGE scores (Figs. 1b-c).
* SGE_IDRLibs_Analysis - Analyzes the X4A IDR library data. Builds Fig. 2d (heatmap of fitness scores for all possible amino acid substitutions, positions 123-147) and Extended Data Fig. 6 (D13 log2-fold changes for multi-site combinatorial Lys->Ala/Lys->Arg/AAE mutants and 6bp deletions/ClinVar indels).
* SGE_InSilicoDeltaDeltaGAnalysis - Computes ThermoMPNN ddG and SASA predictions for BARD1 missense variants (merged into supplementary_file_1's `scores` tab) and ddG predictions for in-frame deletions (ThermoMPNN-I). No panel in the current manuscript figures is drawn directly from this notebook -- it supports ddG/SASA statistics referenced in the text.
* SGE_MAFvsSGEscore - Built what was Extended Data Fig. 6 (MAF vs. fitness score) in an earlier draft; that figure was removed in the revised manuscript and is no longer part of the paper.
* **SGE_MakeFinalDataTable** - Builds supplementary_file_1 - the required input for all figure generating notebooks. Requires all files in /BARD1_SGE_analysis/Data/supp_table_inputs (and the ThermoMPNN/SASA and X4A IDR data under Data/extra_data).
* SGE_NonATG_D17_Comparison - Compares D13 vs. D17 SGE fitness scores for the non-ATG start-codon-region libraries (Extended Data Fig. 8).
* SGE_OrthogonalAssays - Generates histogram and strip plot showing distribution of SGE scores for variants assayed in orthogonal functional assays (Extended Data Fig. 5a).
* SGE_PaperNumberGenerator - Generates numerical values used throughout the main text.
* SGE_ReClassFig - Generates dot plot of points received by each variant after applying BARD1 functional data (Fig. 3e).
* SGE_RNAanalysis - Builds scatter plot of RNA score vs. SGE score (Fig. 4c), lollipop plots of exons 4 and 9 (Fig. 4d), and RNA score stem plots across BARD1 (Extended Data Fig. 9). Also computes an NMD-across-gene plot and an X4G-X4L-only stem plot (manually toggled, not individually figure-numbered).
* SGE_ScoresAcrossGene - Generates scatterplots of fitness score vs. genomic coordinate for each BARD1 exon (Extended Data Fig. 2).
* SGE_VEPs_vs_SGE - Creates scatter plots of predictor score vs. SGE score (Extended Data Fig. 5b) and case-control analysis of variants with moderate evidence towards benignity/pathogenicity from predictors (Extended Data Fig. 5c). Additional unpublished exploratory figures are also generated.
* SGE_ZnBindingAnalysis - Analysis of missense variants impacting Zn2+ coordinating residues in BARD1's RING domain. Generates strip plot (Extended Data Fig. 11) and comparative analysis with BRCA1. **(Needs BRCA1 SGE File)**

## Scripts
The Scripts folder contains the script used to generate counts for the BARD1_X1A_ATG double mutant experiment and the scripts used to generate the structural/helical-wheel figures (ChimeraX and matplotlib). Scripts are labeled by the figure that will be generated and code is annotated.

These scripts are:
* BARD1_X1A_ATG_counter - Generates counts file for all variants in the BARD1_X1A_ATG double mutant experiment.
* SGEColor_ChimeraX_MissenseOnly - Generic, reusable ChimeraX script that colors a protein structure by per-residue missense SGE score. Used to build Fig. 5a (BRCA1-BARD1 RING:RING dimer, PDB 1JM7), Fig. 5d (BARD1/BRCA1 BRCT space-filling models, PDB 3FA2/1T29), and Fig. 5f (BARD1 ARD+BRCT bound to the nucleosome core particle and H4, PDB 7LYC).
* SGE_DrawHelicalWheel - Generates helical-wheel diagrams for BARD1 and BRCA1 (Fig. 5b).
